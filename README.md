# 🐘 Codexeron PHP SDK

Official PHP SDK for the Codexeron Marketplace.

Build powerful integrations with the official Codexeron API.

---

## Features

- Secure Authentication
- Product Management
- Order Management
- User Management
- License Verification
- Search API
- Webhooks

---

## Installation

```bash
composer require codexeron/php-sdk
```
